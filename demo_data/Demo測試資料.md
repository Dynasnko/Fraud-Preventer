## ⚡ 自動填入（Playwright）

不想手打時，用腳本開一個真的瀏覽器，跟真人一樣點開表單、逐字打字、選下拉、上傳檔案（**只填不送出**，送出鍵自己按）：

```bash
pip install playwright                                            # 第一次（預設用電腦上的 Chrome，不用另外下載瀏覽器）
python main.py                                                    # 另一個終端機先啟動系統
python dev_scripts/demo_autofill.py                               # 預設 admin / admin123，每字 30ms
python dev_scripts/demo_autofill.py --delay 15                    # 打字快一點；--fast 直接貼上
python dev_scripts/demo_autofill.py --browser msedge              # 改用 Edge
```

瀏覽器開啟後，在終端機輸入代號：`c1`～`c10` 對話框提示詞、`a1`～`a6` 進階問答、`w` 新增 Worker、`r1`～`r3` 案件通報、`q` 結束。
範例內容在 `dev_scripts/demo_autofill_data.py`，與本文件相同。

## 1. 對話框開場提示詞（詐騙相關）

建議依序問，從簡單到複雜，順便展示 Thinking Log：

1. **基本判斷**
   ```
   我剛收到一封簡訊說「您的包裹因地址不完整無法配送，請於 24 小時內點擊連結補填資料」，這是詐騙嗎？
   ```
2. **話術分析**
   ```
   有人在 LINE 上自稱是檢察官，說我的帳戶涉及洗錢案，要我把存款領出來交給「法院監管人員」，不然會被羈押。這是真的嗎？我該怎麼辦？
   ```
3. **查 165 資料庫（會觸發 `analyze_scam_database` 工具）**
   ```
   根據 165 的案件資料，哪個縣市的詐騙財損金額最高？最常見的詐騙手法是什麼？
   ```
4. **法律問題（多位專家協作）**
   ```
   如果我被朋友騙去把帳戶借給別人使用，結果那個帳戶被拿去收詐騙款，我會觸犯什麼法律？會被判刑嗎？
   ```
5. **追問（展示補充資訊機制）**
   ```
   我被騙了，要怎麼辦？
   ```
   → 系統應該會反問細節，再回答：`我在臉書買演唱會門票，匯了 6,800 元之後賣家就封鎖我了。`
6. **不相關的題目（展示路由到其他專家）**
   ```
   衣索比亞的咖啡豆有什麼風味特色？
   ```
