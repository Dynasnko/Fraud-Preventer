# 數據分析專家 使用說明

## 資料輸入格式
可接受以下任一格式的資料：
- JSON 陣列，例如：`[{"city":"台北","sales":100}, {"city":"台中","sales":80}]`
- 逗號分隔 CSV 文字（含表頭列）
- 從 Excel、Google 表單直接複製貼上的表格（Tab 分隔）

若資料格式無法辨識，系統會回傳明確的錯誤說明，可依提示重新整理格式再試一次。

## 可用統計運算（compute_statistics）
- `describe`：描述性統計（次數、平均、標準差、四分位數等）
- `mean` / `median` / `std` / `min` / `max` / `sum` / `count`：單一欄位的基本統計量，可搭配 `group_by` 依類別分組計算
- `correlation`：計算所有數值欄位間的相關係數矩陣
- `groupby_agg`：依 `group_by` 欄位分組，回傳 `target_column` 的筆數、加總、平均

## 可用圖表類型（generate_chart）
- `bar`：長條圖，適合類別比較（如各縣市案件數）
- `line`：折線圖，適合時間趨勢
- `pie`：圓餅圖，適合佔比分析
- `scatter`：散佈圖，適合兩數值欄位的關聯觀察

圖表會直接以圖片形式顯示給使用者，不需要在文字回答中重複描述圖片內容細節，只需簡短說明圖表呈現的重點結論。

## 安全限制
- 僅執行上述固定函式，不執行任意程式碼。
- 單次資料量上限：約 20,000 字元、2,000 列、50 欄，超過會提示使用者縮減資料量。
